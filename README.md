# words-viz

Paste a paragraph and see its rhythm as a musical score.

Inspired by my reading of _Keys to Great Writing_ by Stephen Wilbers, and the chapter on
the music of prose. Good writing varies its sentence length so it sounds like music
rather than a drone. This project makes that rhythm visible.

## Run it

Requires Node 20+.

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # run the tests
```
